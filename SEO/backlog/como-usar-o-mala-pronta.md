# Como usar o Mala Pronta para preparar sua mala

- **Status:** A refinar
- **Keyword alvo:** "mala pronta app" / "como usar mala pronta"

## Ângulo
Tutorial direto voltado para quem acabou de baixar ou está considerando. Mostra o fluxo completo de uso — do primeiro acesso até a mala pronta — com foco em rapidez e no valor de cada etapa. Diferente do artigo "como fazer lista de viagem", aqui o app é o protagonista.

## Estrutura sugerida
- Primeiro acesso (criar viagem, escolher destino e duração)
- Como a lista é gerada (lógica por destino e duração)
- Personalizando a lista (adicionar, remover, marcar como feito)
- Usando na hora de fazer a mala (marcar itens conforme guarda)
- Dicas para aproveitar melhor
